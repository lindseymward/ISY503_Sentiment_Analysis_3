# Amazon Review Sentiment Analysis System

This project implements a machine learning-based sentiment analysis system using Amazon product reviews. The model uses TF-IDF vectorisation and Logistic Regression to classify reviews as positive or negative.

## Live Application
Streamlit App:
https://sentimentanalysis3-dreamteam.streamlit.app

## GitHub Repository
This repository contains all source code and model files required to run the system.

## How to Run Locally
If the deployed Streamlit application is unavailable at the time of marking, the system can be run locally using the following command:

streamlit run app.py

## Files Included
- app.py (Streamlit web application)
- sentiment_model.pkl (trained model)
- requirements.txt (dependencies)
